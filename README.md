# Детекция дронов с YOLOv8s

Лабораторная работа 4, задача 1, вариант 3. Модель получает изображение и возвращает прямоугольники с классом `Drone` и оценкой уверенности.

[Разбор кода, экспериментов и метрик](PROJECT_EXPLAINED.md).

Использованы все 343 изображения из предоставленного экспорта. Три полигона преобразованы в охватывающие прямоугольники в рабочей копии. Для обучения выделено 241 изображение, для валидации и теста — по 51. Кадры упорядочены по медианной доле площади изображения, которую занимают размеченные рамки. Затем кадры каждой из трёх групп размера случайно распределены по выборкам с seed 42. Медианная доля площади рамки по кадрам составила 3,08% в обучении, 2,98% на валидации и 2,81% в тесте. В разных выборках могут встречаться похожие кадры одного ролика, поэтому тест характеризует качество на отложенных кадрах из этого набора. [Размеченный датасет Roboflow](https://app.roboflow.com/ackepters-workspace/algo-lab-4/2) доступен участникам проекта.

## Воспроизведение

Для запуска на NVIDIA понадобится сборка PyTorch с CUDA. Для дообучения нужны предобученные веса COCO `yolov8s.pt` в корне проекта. [Релиз весов Ultralytics](https://github.com/ultralytics/assets/releases/download/v8.4.0/yolov8s.pt).

```powershell
python -m pip install ultralytics==8.4.115
python -m pip install --upgrade torch torchvision --index-url https://download.pytorch.org/whl/cu128
python prepare_dataset.py
python train.py
```

На компьютере, где обучалась модель, CUDA-пакеты установлены отдельно от системного Python. Для повторного запуска в этом же проекте достаточно подключить их перед вызовом `train.py` или `infer.py`.

```powershell
$env:PYTHONPATH = (Resolve-Path .cuda-packages).Path
```

`prepare_dataset.py` создаёт рабочую копию в `dataset/detection` и записывает списки для `dataset/data.yaml`. `train.py` стартует с предобученных весов COCO и дообучает модель на RTX 4050 за 30 эпох с размером входа 512 и batch size 8. На тесте оцениваются веса с лучшим mAP@50–95 по валидации.

## Инференс

```powershell
python infer.py "путь_к_фото_или_видео"
```

Можно передать папку вместо файла. Результаты сохраняются в `runs/predict` или в следующей пронумерованной папке.

## Результаты случайного разбиения

На 51 тестовом кадре с 53 размеченными дронами модель получила mAP@50 0,982, precision 0,959 и recall 0,981. Более высокие метрики получены на другом тестовом наборе, в котором есть кадры тех же роликов, что и в обучении. Разницу с экспериментами ниже нельзя целиком приписать улучшению модели.

## Предыдущие эксперименты

Следующие прогоны использовали прежнее разбиение по роликам. Оба стартовали с весов COCO `yolov8s.pt` и прошли по 30 эпох на NVIDIA GeForce RTX 4050 Laptop GPU. Использованы PyTorch 2.11.0 с CUDA 12.8 и Ultralytics 8.4.115.

| Размер входа | Лучший mAP@50–95 на val | mAP@50 на test | Precision на test | Recall на test |
| --- | ---: | ---: | ---: | ---: |
| 512 × 512 | 0,319 | 0,257 | 0,611 | 0,235 |
| 768 × 768 | 0,324 | 0,210 | 0,877 | 0,196 |

Тест состоит из 51 изображения с 51 дроном. Медианная размеченная рамка занимает около 0,4% площади тестового изображения и 3,5% площади обучающего. В тесте 41 из 51 кадра взяты из одного видео, поэтому оценка сильно зависит от этой сцены.
